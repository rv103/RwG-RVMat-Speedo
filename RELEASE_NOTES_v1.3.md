RwG RVMat Speedo **v1.3** — custom textures + dark UI.

Drag & drop a `.rvmat` onto a field to spawn its worn / damage / destruct variant
(the right `_mc` is swapped into `Stage3`, original untouched).

**New**
- **Custom Textures** — set your **own** `_mc` paths for Worn / Damage / Destruct
  (type or Browse) and drop a `.rvmat` onto their fields to bake them in.
- **Save / Load presets** — store your custom paths under a name and reload them
  in one click (Delete with confirm). Kept in `rvmat_speedo_presets.json` next to
  the app.

**Changed**
- **Dark RwG interface** matching the RwG Texture Converter — green accents, a
  titled header, **green hover** on drop fields, an app icon, auto-sized window.

**Unchanged**
- The `.rvmat` rewrite (Stage3 swap, optional NOHQ/AS/SMDI defaults, `_worn` /
  `_damage` / `_destruct` suffix) and all built-in DayZ categories.

**Download:** `RwG_RVMat_Speedo.exe` below — no Python needed. Windows SmartScreen
may warn on first run (unsigned app): **More info → Run anyway**. Requires
[tkinterdnd2] only if running from source.

See [`CHANGELOG.md`](CHANGELOG.md) and the [Wiki](../../wiki) for details.
